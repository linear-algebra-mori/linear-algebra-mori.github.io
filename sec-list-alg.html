    Section 4.3 リストとアルゴリズム

    Subsection 4.3.1 ガウスの前進消去

    実際に与えられたベクトルのスパンや線形独立性に関するアルゴリズムを考える。 次の補題は本質的に重要である。
    🔗

    補題 4.3.1.

    任意の \(\bm{v}_1,\dotsc,\bm{v}_k\in\mathbb{R}^n\) と \(c\in\mathbb{R}\) と \(1\le s \lt t\le n\) について、\(\bm{v}'_1,\dotsc,\bm{v}'_k\in\mathbb{R}^n\) を
    \begin{align*} \bm{v}'_t\amp=\bm{v}_t+c\bm{v}_s\\ \bm{v}'_i\amp=\bm{v}_i\qquad\qquad\forall i\in\{1,\dotsc,k\}\setminus\{t\} \end{align*}
    と定義する。このとき、任意の \(j\in\{1,2,\dotsc,k\}\) について、
    \begin{equation*} \mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_j) = \mathrm{span}(\bm{v}'_1,\dotsc,\bm{v}'_j). \end{equation*}
    🔗
    🔗

    証明.
    まず \(\mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_j) \supseteq \mathrm{span}(\bm{v}'_1,\dotsc,\bm{v}'_j)\) は自明である。また、\(\bm{v}'_t \leftarrow\bm{v}'_t-c\bm{v}'_s\) とすることで、元の \(\bm{v}_1,\dotsc,\bm{v}_j\) が復元できるので、同様に \(\mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_j) \subseteq \mathrm{span}(\bm{v}'_1,\dotsc,\bm{v}'_j)\) である。 よって \(\mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_j) = \mathrm{span}(\bm{v}'_1,\dotsc,\bm{v}'_j)\) は示された。
    🔗
    🔗
    ベクトルの集合の要素に重複を許し順序を与えると便利なので、順序付きの多重集合としてリストを導入する。
    🔗

    定義 4.3.2. リスト.

    \(\bm{v}_1,\dotsc,\bm{v}_k\in \mathbb{R}^n\) について、ベクトルの列 \((\bm{v}_1,\dotsc,\bm{v}_k)\) をベクトルのリストという。 括弧を省略して \(\bm{v}_1,\dotsc,\bm{v}_n\) と表すこともある。
    🔗
    🔗

    アルゴリズム 4.3.3. ガウスの消去法の前進消去.

    • 入力: リスト \(\bm{v}_1,\dotsc,\bm{v}_k\in\mathbb{R}^n\)
      🔗
    • 出力: リスト \(\bm{v}'_1,\dotsc,\bm{v}'_k\in\mathbb{R}^n\) で任意の \(j\in\{1,\dotsc,k\}\) について以下の二条件を満たすもの。
      1. \(\mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_j) = \mathrm{span}(\bm{v}'_1,\dotsc,\bm{v}'_j)\text{.}\)
        🔗
      2. \(\mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_{j})=\mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_{j-1})\implies \bm{v}'_j=\bm{0}\text{.}\)
        🔗
      🔗
      🔗
    アルゴリズムの疑似コード
    🔗
    1. \(\displaystyle (\bm{v}'_1,\dotsc,\bm{v}'_k) \leftarrow (\bm{v}_1,\dotsc,\bm{v}_k)\)
      🔗
    2. for \(i=1,\dotsc,k\) :
      🔗
    3.     If \(\bm{v}'_i=\bm{0}\) : continue (2行目に戻る)
      🔗
    4.     \(p_i\leftarrow \bm{v}'_i\) の非零成分のインデックス(どれでもよい、ピボットと呼ばれる)
      🔗
    5.     \(\bm{v}'_i\leftarrow \frac1{(\bm{v}'_i)_{p_i}}\bm{v}'_i\)
      🔗
    6.     for \(j=i+1,\dotsc,k\) :
      🔗
    7.         \(\bm{v}'_j\leftarrow\bm{v}'_j-(\bm{v}'_j)_{p_i}\bm{v}'_i\)
      🔗
    8. return \((\bm{v}'_1,\dotsc,\bm{v}'_k)\)
      🔗
    🔗

    証明.
    このアルゴリズムの正当性を証明する。
    🔗
    まず、スパンが保存されていることを証明する。 このアルゴリズムの中で \(\bm{v}'_1,\dotsc,\bm{v}'_k\) を更新しているが、それは5行目と7行目である。 5行目の更新はベクトルに非零のスカラー倍をする操作であるが、明らかにスパンは変化しない。 7行目の更新は 補題 4.3.1 よりスパンを変えない。
    🔗
    次に
    \begin{equation*} \mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_{j})=\mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_{j-1}) \end{equation*}
    を仮定する。スパンの保存条件より
    \begin{equation*} \mathrm{span}(\bm{v}'_1,\dotsc,\bm{v}'_{j})=\mathrm{span}(\bm{v}'_1,\dotsc,\bm{v}'_{j-1}) \end{equation*}
    が成り立つ。 したがって
    \begin{equation*} \bm{v}'_{j}\in\mathrm{span}(\bm{v}'_1,\dotsc,\bm{v}'_{j-1}) \end{equation*}
    である。 よって、ある \(a_1,\dotsc,a_{j-1}\in\mathbb{R}\) が存在し、
    \begin{equation*} \bm{v}'_j = a_1\bm{v}'_1+\dotsb+a_{j-1}\bm{v}'_{j-1} \end{equation*}
    が成り立つ。 ここで \(\bm{v}'_1\ne\bm{0}\) のとき、\(\bm{v}'_1,\dotsc,\bm{v}'_j\) の中で \(p_1\) 成分が非零なのは \(\bm{v}'_1\) だけである。よって、\(a_1=0\) である。 したがって、
    \begin{equation*} \bm{v}'_j = a_2\bm{v}'_2+\dotsb+a_{j-1}\bm{v}'_{j-1} \end{equation*}
    が成り立つ(\(\bm{v}'_1=\bm{0}\) のときも明らかに成り立つ)。 同じ議論を繰り返すことで、\(\bm{v}'_j = \bm{0}\) であることが分かる。
    🔗
    🔗

    練習問題 4.3.4. ガウスの前進消去.

    以下のリストに対してガウスの前進消去を実行せよ。
    \begin{align*} \bm{v}_1\amp=\begin{bmatrix}1\\1\\2\\2\end{bmatrix},\amp \bm{v}_2\amp=\begin{bmatrix}1\\0\\1\\0\end{bmatrix},\amp \bm{v}_3\amp=\begin{bmatrix}0\\1\\0\\1\end{bmatrix},\amp \bm{v}_4\amp=\begin{bmatrix}1\\1\\-1\\-1\end{bmatrix}. \end{align*}
    🔗
    🔗
    🔗

    Subsection 4.3.2 アルゴリズムの応用

    アルゴリズム 4.3.3は様々な計算に使える汎用的なものである。 例えば補題 4.1.6より、ベクトルがスパンに含まれるか判定問題を解くことができる。
    🔗

    事実 4.3.5. スパンのメンバーシップ問題.

    問題
    🔗
    入力: \(\bm{v}_1,\dotsc,\bm{v}_k,\bm{v}_{k+1}\in\mathbb{R}^n\)
    🔗
    出力: \(\text{Yes}\iff\bm{v}_{k+1}\in\mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_k)\)
    は以下のアルゴリズムで解ける。
    🔗
    アルゴリズム 4.3.3を \(\bm{v}_1,\dotsc,\bm{v}_k,\bm{v}_{k+1}\) に対して実行し、\(\bm{v}'_{k+1}=\bm{0}\) であれば Yes を、そうでなければ No を出力する。
    🔗
    🔗

    事実 4.3.6. 線形独立性の判定問題.

    問題
    🔗
    入力: \(\bm{v}_1,\dotsc,\bm{v}_k\in\mathbb{R}^n\)
    🔗
    出力: \(\text{Yes}\iff\{\bm{v}_1,\dotsc,\bm{v}_k\}\) が線形独立
    は以下のアルゴリズムで解ける。
    🔗
    アルゴリズム 4.3.3を \(\bm{v}_1,\dotsc,\bm{v}_k\) に対して実行し、\(\bm{v}'_{i}=\bm{0}\) となる \(i\in\{1,\dotsc,i\}\) が存在すれば No を、そうでなければ Yes を出力する。
    🔗
    🔗

    定理 4.3.7.

    \(n\) 次元数ベクトル空間の線形独立なベクトルの個数は \(n\) 以下。
    🔗
    🔗

    証明.
    \(\bm{v}_1,\dotsc,\bm{v}_k\in\mathbb{R}^n\) が線形独立であるとすると、アルゴリズム 4.3.3 はすべての \(i\in\{1,\dotsc,k\}\) について、ピボット \(p_i\in\{1,2,\dotsc,n\}\) を与えるが、これは互いに異なるため、\(k\le n\) である。
    🔗
    🔗
