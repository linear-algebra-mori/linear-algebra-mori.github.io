定理 7.6.13 余因子行列と逆行列.

任意の正方行列 \(A\in\mathbb{R}^{n\times n}\) について
\begin{equation*} \mathrm{adj}(A)A = A\,\mathrm{adj}(A) = \det(A)I. \end{equation*}
🔗
特に \(\det(A)\ne 0\) のとき、
\begin{equation*} A^{-1} = \frac1{\det(A)}\mathrm{adj}(A). \end{equation*}
🔗
🔗

証明.
\(\mathrm{adj}(A)A\) の \((i,j)\) 成分は
\begin{equation*} \sum_{k=1}^n \widetilde{a}_{i,k}a_{k,j} \end{equation*}
である。特に \(j=i\) の場合は
\begin{equation*} \sum_{k=1}^n \widetilde{a}_{i,k}a_{k,i} \end{equation*}
であるが、これは \(A\) の行列式の \(i\) 列目に対する余因子展開である。 したがって、\(\mathrm{adj}(A)A\) の \((i,i)\) 成分は \(\det(A)\) である。
🔗
\(i\ne j\) の場合を考える。\(A\) の \(i\) 列目を \(j\) 列目に置き換えた行列を \(B=[b_{i,j}]\) とおくと、
\begin{align*} \sum_{k=1}^n \widetilde{a}_{i,k}a_{k,j}\amp= \sum_{k=1}^n(-1)^{i+k}\det(\widetilde{A}_{k,i})a_{k,j}\\ \amp= \sum_{k=1}^n(-1)^{i+k}\det(\widetilde{B}_{k,i})b_{k,j}\\ \amp= \sum_{k=1}^n(-1)^{i+k}\det(\widetilde{B}_{k,i})b_{k,i}\\ \amp= \det(B)=0 \end{align*}
一つ目の等号は余因子行列の定義である。 二つ目の等号は \(A\) と \(B\) が \(i\) 列目のみ異なることから従う。 三つ目の等号は \(B\) の \(i\) 列目が \(j\) 列目と等しいことから従う。 四つ目の等号は \(B\) の \(i\) 列目の余因子展開から従う。 最後の等号は \(B\) が二つ同じ列を持つことから、行列式の交代性より従う。 したがって、\(\mathrm{adj}(A)A\) の非対角成分は0である。
🔗
\(A\,\mathrm{adj}(A)\) についても同様に示せる。
