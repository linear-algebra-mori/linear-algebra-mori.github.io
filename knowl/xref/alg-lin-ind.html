アルゴリズム 4.2.6. 数ベクトルの線形独立性判定アルゴリズム.

🔗
入力: \(\bm{v}_1,\dotsc,\bm{v}_k\in\mathbb{R}^n\)
🔗
出力: \(\bm{v}_1,\dotsc,\bm{v}_k\in\mathbb{R}^n\) が線形独立かどうか？
  1. for \(i=1,\dotsc,k\) :
    🔗
  2.     If \(\bm{v}_i=\bm{0}\) : return No
    🔗
  3.     \(p_i\leftarrow \bm{v}_i\) の非零成分のインデックス(どれでもよい)。
    🔗
  4.     \(\bm{v}_i\leftarrow \frac1{(\bm{v}_i)_{p_i}}\bm{v}_i\)
    🔗
  5.     for \(j=i+1,\dotsc,k\) :
    🔗
  6.         \(\bm{v}_j\leftarrow\bm{v}_j-(\bm{v}_j)_{p_i}\bm{v}_i\)
    🔗
  7. return Yes
    🔗
🔗

証明.
このアルゴリズムの正当性を証明する。
🔗
このアルゴリズムの中で \(\bm{v}_1,\dotsc,\bm{v}_k\) を更新しているが、線形独立性は変化していない。 4行目で \(\bm{v}_i\) をスカラー(非零)倍しているが、これによって線形独立性は変化しない。 6行目の更新は 補題 4.2.5 より線形独立性を変えない。
🔗
2行目で \(\bm{v}_i=\bm{0}\) のときは明らかに線形従属であるので No を返すのは正当である。 7行目に到達したときに、\(\bm{v}_1,\dotsc,\bm{v}_k\) が線形独立であることを示す。
\begin{equation*} a_1\bm{v}_1+\dotsb+a_k\bm{v}_k=\bm{0} \end{equation*}
とする。 このとき、\(\bm{v}_1\) の \(p_1\) 成分は非零であり、\(\bm{v}_2,\dotsc,\bm{v}_k\) の \(p_1\) 成分は零である。よって \(a_1=0\) である。 次に \(a_1=0\) を仮定すると、同様の議論から \(a_2=0\) である。 この議論を繰り返すことで、\(a_1=\dotsb=a_k=0\) である。 よって \(\bm{v}_1,\dotsc,\bm{v}_k\) は線形独立である。
