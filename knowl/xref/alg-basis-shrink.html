アルゴリズム 4.4.8. 基底抽出アルゴリズム.

🔗
入力: \(\bm{v}_1,\dotsc,\bm{v}_k\in\mathbb{R}^n\)
🔗
出力: \(\bm{v}_{i_1},\dotsc,\bm{v}_{i_r}\in\mathbb{R}^n\) が基底となるような \(1\le i_1\lt\dotsc\lt i_r\le m\)
  1. \(B\leftarrow ()\)  (空のリストで初期化)
    🔗
  2. for \(i=1,\dotsc,k\) :
    🔗
  3.     If \(\bm{v}_i=\bm{0}\) : continue (2行目に戻る)
    🔗
  4.     \(B\leftarrow B,i\)
    🔗
  5.     \(p_i\leftarrow \bm{v}_i\) の非零成分のインデックス(どれでもよい)。
    🔗
  6.     \(\bm{v}_i\leftarrow \frac1{(\bm{v}_i)_{p_i}}\bm{v}_i\)
    🔗
  7.     for \(j=i+1,\dotsc,k\) :
    🔗
  8.         \(\bm{v}_j\leftarrow\bm{v}_j-(\bm{v}_j)_{p_i}\bm{v}_i\)
    🔗
  9. return \(B\)
    🔗
🔗
