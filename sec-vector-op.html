    Section 1.2 数ベクトルの和とスカラー倍

    Subsection 1.2.1 数ベクトルの和とスカラー倍の定義

    数ベクトルには和(足し算)とスカラー倍という2つの演算が定義される。
    🔗

    定義 1.2.1. 数ベクトルの和.

    \(n\) 次元実ベクトル
    \begin{align*} \bm{v} \amp= [v_i]_i = \begin{bmatrix} v_1\\ v_2\\ \vdots\\ v_n \end{bmatrix}\in\mathbb{R}^n,\amp \bm{w} \amp= [w_i]_i = \begin{bmatrix} w_1\\ w_2\\ \vdots\\ w_n \end{bmatrix}\in\mathbb{R}^n \end{align*}
    について、\(\bm{v}+\bm{w}\in\mathbb{R}^n\) を
    \begin{equation*} \bm{v} + \bm{w} \coloneqq [v_i+w_i]_i = \begin{bmatrix} v_1+w_1\\ v_2+w_2\\ \vdots\\ v_n+w_n \end{bmatrix} \end{equation*}
    と定義する。 次元が異なる数ベクトル同士の和は定義されない。
    🔗
    🔗

    定義 1.2.2. 数ベクトルのスカラー倍.

    \(n\) 次元数ベクトル
    \begin{equation*} \bm{v} = [v_i]_i = \begin{bmatrix} v_1\\ v_2\\ \vdots\\ v_n \end{bmatrix}\in\mathbb{R}^n \end{equation*}
    とスカラー \(c\in\mathbb{R}\) について、\(c\bm{v}\) を
    \begin{equation*} c\bm{v}\coloneqq [cv_i]_i = \begin{bmatrix} cv_1\\ cv_2\\ \vdots\\ cv_n \end{bmatrix} \end{equation*}
    と定義する。
    🔗
    🔗
    また、\(-\bm{v}:=(-1)\bm{v}\) と定義する。つまり
    \begin{equation*} -\bm{v}= [-v_i]_i = \begin{bmatrix} -v_1\\ -v_2\\ \vdots\\ -v_n \end{bmatrix} \end{equation*}
    である。
    🔗
    さらに、数ベクトル \(\bm{v},\,\bm{w}\in\mathbb{R}^n\) に対して差(引き算)を \(\bm{v}-\bm{w}:=\bm{v}+(-\bm{w})\) と定義する。つまり
    \begin{equation*} \bm{v} - \bm{w} = [v_i-w_i]_i = \begin{bmatrix} v_1-w_1\\ v_2-w_2\\ \vdots\\ v_n-w_n \end{bmatrix} \end{equation*}
    である。
    🔗
    零ベクトル \(\bm{0}\in\mathbb{R}^n\) は成分がすべて0である数ベクトルである。 単に \(\bm{0}\) と書くと次元が分からないので、\(\bm{0}_n\) と書く方が間違いがないが、大抵の場合は次元は文脈上明らかなので単に \(\bm{0}\) と表す。
    🔗
    🔗

    Subsection 1.2.2 数ベクトルの演算の性質

    数ベクトルの和について以下の性質が成り立つことは簡単に確認できる。
    🔗
    任意の自然数 \(n\in\mathbb{N}\) と \(\bm{x},\,\bm{y},\,\bm{z}\in\mathbb{R}^n\) について
    🔗
    • [結合法則] \((\bm{x}+\bm{y})+\bm{z} = \bm{x}+(\bm{y}+\bm{z})\)
      🔗
    • [交換法則] \(\bm{x}+\bm{y} = \bm{y}+\bm{x}\)
      🔗
    • [単位元の存在] \(\bm{0}+\bm{x} = \bm{x}+\bm{0} = \bm{x}\)
      🔗
    • [逆元の存在] \(\bm{x}+(-\bm{x}) = \bm{0}\)
      🔗
    同様にスカラー倍について以下の性質が成り立つことは簡単に確認できる。 任意の自然数 \(n\in\mathbb{N}\) と \(\bm{x}\in\mathbb{R}^n\) と \(a,\,b\in\mathbb{R}\) について
    🔗
    • [結合法則] \((ab)\bm{x} = a(b\bm{x})\)
      🔗
    • [単位元] \(1\bm{x} = \bm{x}\)
      🔗
    さらに、数ベクトルの和とスカラー倍について以下の性質が成り立つことは簡単に確認できる。 任意の自然数 \(n\in\mathbb{N}\) と \(\bm{x},\,\bm{y}\in\mathbb{R}^n\) と \(a,\,b\in\mathbb{R}\) について
    🔗
    • [分配法則] \((a+b)\bm{x} = a\bm{x} + b\bm{x}\)
      🔗
    • [分配法則] \(a(\bm{x}+\bm{y}) = a\bm{x} + a\bm{y}\)
      🔗
    🔗
    🔗
