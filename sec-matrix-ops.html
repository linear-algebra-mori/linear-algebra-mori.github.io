    Section 2.7 行列の和とスカラー倍

    Subsection 2.7.1 行列の和とスカラー倍の定義

    定義 2.7.1. 行列の和.

    \(n\times m\) 行列 \(A=[a_{i,j}]_{i,j},\,B=[b_{i,j}]_{i,j}\) について、その和を \(A+B\coloneqq[a_{i,j}+b_{i,j}]_{i,j}\) と定義する。 型が異なる行列同士の和は定義されない。
    🔗
    🔗

    定義 2.7.2. 行列のスカラー倍の定義.

    スカラー \(c\) と \(n\times m\) 行列 \(A=[a_{i,j}]_{i,j}\) について、スカラー倍を \(cA\coloneqq[c a_{i,j}]_{i,j}\) と定義する。
    🔗
    🔗
    数ベクトルの場合と同様に \(-A\coloneqq (-1)A\) と定義する。また、\(A-B\coloneqq A+(-B)\) と定義する。
    🔗
    \(n\) 次元数ベクトルを \(n\times 1\)行列とみなしても演算のルールとしては矛盾が生じない。
    🔗
    🔗

    Subsection 2.7.2 行列の和とスカラー倍の線型写像としての意味

    命題 2.7.3.

    任意の自然数 \(n,\,m\in\mathbb{N}\)と \(A,\,B\in\mathbb{R}^{n\times m}\) と \(c\in\mathbb{R}\) と \(\bm{v}\in\mathbb{R}^m\) について
    \begin{gather*} (cA)\bm{v} = c(A\bm{v})\\ (A+B)\bm{v} = A\bm{v} + B\bm{v}. \end{gather*}
    🔗
    🔗

    証明.
    行列 \(\times\) 数ベクトルの定義
    \begin{equation*} A\bm{v}=[a_{i,1}v_1+a_{i,2}v_2+\dotsb+a_{i,m}v_m]_i \end{equation*}
    と行列のスカラー倍の定義
    \begin{equation*} cA=[ca_{i,j}]_{i,j} \end{equation*}
    より
    \begin{align*} (cA)\bm{v} \amp= [(ca_{i,1})v_1+(ca_{i,2})v_2+\dotsb+(ca_{i,m})v_m]_i\\ \amp= c[a_{i,1}v_1+a_{i,2}v_2+\dotsb+a_{i,m}v_m]_i\\ \amp= c(A\bm{v}). \end{align*}
    🔗
    行列の和の定義
    \begin{equation*} A+B=[a_{i,j}+b_{i,j}]_{i,j} \end{equation*}
    より
    \begin{align*} (A+B)\bm{v} \amp= [(a_{i,1}+b_{i,1})v_1+(a_{i,2}+b_{i,2})v_2+\dotsb+(a_{i,m}+b_{i,m})v_m]_i\\ \amp= [a_{i,1}v_1+a_{i,2}v_2+\dotsb+a_{i,m}v_m]_i\\ \amp\qquad + [b_{i,1}v_1+b_{i,2}v_2+\dotsb+b_{i,m}v_m]_i\\ \amp= A\bm{v} + B\bm{v}. \end{align*}
    🔗
    🔗
    🔗

    Subsection 2.7.3 行列の和とスカラー倍のその他の性質

    数ベクトルの和とスカラー倍と同様に以下の性質が成り立つ。
    🔗
    任意の自然数 \(n,\,m\in\mathbb{N}\) と \(A,\,B,\,C\in\mathbb{R}^{n\times m}\) について
    🔗
    • [結合法則] \((A+B)+C = A+(B+C)\)
      🔗
    • [交換法則] \(A+B = B+A\)
      🔗
    • [単位元の存在] \(O+A = A+O = A\)
      🔗
    • [逆元の存在] \(A+(-A) = O\)
      🔗
    任意の自然数 \(n,\,m\in\mathbb{N}\) と \(A\in\mathbb{R}^{n\times m}\) と \(a,\,b\in\mathbb{R}\) について
    🔗
    • [結合法則] \((ab)A = a(bA)\)
      🔗
    • [単位元] \(1A = A\)
      🔗
    任意の自然数 \(n,\,m\in\mathbb{N}\)と \(A,\,B\in\mathbb{R}^{n\times m}\) と \(a,\,b\in\mathbb{R}\) について
    🔗
    • [分配法則] \((a+b)A = aA + bA\)
      🔗
    • [分配法則] \(a(A+B) = aA + aB\)
      🔗
    🔗
    🔗
