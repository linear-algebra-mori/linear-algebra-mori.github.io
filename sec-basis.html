    Section 4.4 基底と次元

    定義 4.4.1. 基底.

    線形空間 \(V\subseteq\mathbb{R}^n\) と \(\bm{v}_1,\dotsc,\bm{v}_k\in \mathbb{R}^n\) について \(\{\bm{v}_1,\dotsc,\bm{v}_k\}\) が \(V\) の基底 \(\defiff\)
    • \(\{\bm{v}_1,\dotsc,\bm{v}_k\}\) が \(V\) の生成系
      🔗
    • \(\{\bm{v}_1,\dotsc,\bm{v}_k\}\) が線形独立
      🔗
    🔗
    基底に含まれる数ベクトルに順序を与えたもの \((\bm{v}_1,\dotsc,\bm{v}_k)\) を順序付き基底という。
    🔗
    🔗
    定理 4.3.7より、任意の線形空間 \(V\subseteq\mathbb{R}^n\) の任意の基底のサイズは \(n\) 以下である。
    🔗
    線形独立性のみに注目して基底を特徴付けることができる。
    🔗

    命題 4.4.2.

    任意の線形空間 \(V\subseteq\mathbb{R}^n\) と \(S\subseteq V\) について以下は同値。
    1. \(S\) は \(V\) の基底
      🔗
    2. \(S\) は線形独立であり、任意の \(T\subseteq V\) で \(T\supsetneq S\) であるものは線形従属(\(S\) は \(V\) の極大な線形独立集合)
      🔗
    🔗
    🔗

    証明.
    \(1\implies 2\) : 基底の定義より \(S\) は線形独立。また、\(S\) は \(V\) の生成系なので、任意の \(\bm{v}\in V\) について、\(\bm{v}\in\mathrm{span}(S)\) である。よって系 4.2.6より、\(S\cup\{\bm{v}\}\) は線形従属。
    🔗
    \(2\implies 1\) : 任意の \(\bm{v}\in V\setminus S\) について、\(S\cup\{\bm{v}\}\) は線形従属である。 \(S\) が線形独立であることから、命題 4.2.7 の二番目の条件より \(\bm{v}\in\mathrm{span}(S)\) である。 よって \(S\) は \(V\) の生成系であり、基底である。
    🔗
    🔗
    したがって、以下の二つの系を得る。
    🔗

    系 4.4.3.

    任意の線形空間 \(V\subseteq\mathbb{R}^n\) は基底を持つ。
    🔗

    系 4.4.4. 基底の延長定理.

    任意の線形空間 \(V\subseteq\mathbb{R}^n\) と線形独立なベクトル \(\bm{v}_1,\dotsc,\bm{v}_k\in V\) について、\(\bm{v}_1,\dotsc,\bm{v}_k\) を含む \(V\) の基底が存在する。
    🔗
    🔗
    また、生成系の観点から基底を特徴付けることもできる。
    🔗

    命題 4.4.5.

    任意の線形空間 \(V\subseteq\mathbb{R}^n\) と有限集合 \(S\subseteq V\) について以下は同値。
    1. \(S\) は \(V\) の基底
      🔗
    2. \(S\) は \(V\) の生成系であり、任意の \(T\subsetneq S\) は \(V\) の生成系でない(\(S\) は \(V\) の極小な生成系)
      🔗
    🔗
    🔗

    証明.
    \(1\implies 2\) : 基底の定義より \(S\) は \(V\) の生成系。 \(S\) が線形独立であることから 命題 4.2.7 より、任意の \(\bm{v}\in S\) について、\(\bm{v}\notin\mathrm{span}(S\setminus\{\bm{v}\})\) である。 よって、\(S\setminus\{\bm{v}\}\) は \(V\) の生成系ではない。
    🔗
    \(2\implies 1\) : 仮定より、任意の \(\bm{v}\in S\) について \(S\setminus\{\bm{v}\}\) は生成系ではない。 よって、\(\bm{v}\notin\mathrm{span}(S\setminus\{\bm{v}\})\) である。 このことから命題 4.2.7より、\(S\) は線形独立である。 したがって、\(S\) は \(V\) の基底である。
    🔗
    🔗

    補題 4.4.6.

    任意の \(\bm{v}_1,\dotsc,\bm{v}_m\in \mathbb{R}^n\) について、\(\mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_m)\) に含まれる線形独立集合のサイズは高々 \(m\) である。
    🔗
    🔗

    証明.
    \(V = \mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_m)\) とおく。 \(\bm{u}_1,\dotsc,\bm{u}_k\in V\) が線形独立であると仮定する。 このとき、\(k\gt m\) を仮定して矛盾を導く。
    🔗
    リスト \(\bm{u}_k,\bm{v}_1,\dotsc,\bm{v}_m\) は線形従属であるので、命題 4.2.7より、ある \(i\in\{1,\dotsc,m\}\) が存在して、\(\bm{v}_i\in\mathrm{span}(\bm{u}_k,\bm{v}_1,\dotsc,\bm{v}_{i-1})\) である。 よって、\(\{\bm{u}_k,\bm{v}_1,\dotsc,\bm{v}_{i-1},\bm{v}_{i+1},\dotsc,\bm{v}_m\}\) は \(V\) の生成系である。 これを繰り替えすことで \(\bm{u}_{k-1},\bm{u}_{k-2},\dotsc\) を順番に生成系のリストの先頭に追加していき、要素数 \(m\) の \(V\) の生成系をアップデートしていく。 このとき、\(\bm{u}_1,\dotsc,\bm{u}_k\) は線形独立なので削除されることはない。 \(k\gt m\) より、\(\bm{u}_1\) を追加する前に \(\bm{v}_i\) はすべて削除されている。 よって、\(\bm{u}_2,\dotsc,\bm{u}_k\) の部分集合が \(V\) の生成系になる。 このとき、\(\bm{u}_1\in\mathrm{span}(\bm{u}_2,\dotsc,\bm{u}_k)\) となるが、これは \(\bm{u}_1,\dotsc,\bm{u}_k\) の線形独立性に矛盾。 よって、\(k\le m\) である。
    🔗
    🔗

    命題 4.4.7.

    任意の線形空間 \(V\subseteq\mathbb{R}^n\) について、\(V\) の基底のサイズは一定。
    🔗
    🔗

    証明.
    \(\bm{u}_1,\dotsc,\bm{u}_\ell\) と \(\bm{v}_1,\dotsc,\bm{v}_k\) を \(V\) の基底とする。 \(\bm{u}_1,\dotsc,\bm{u}_\ell\) は線形独立であり、\(\bm{v}_1,\dotsc,\bm{v}_k\) は \(V\) を張るので補題 4.4.6より、\(\ell\le k\) である。同様に \(k\le \ell\) なので、\(k=\ell\) である。
    🔗
    🔗

    定義 4.4.8. 次元.

    線形空間 \(V\subseteq\mathbb{R}^n\) について、その基底のサイズを \(V\) の次元といい、\(\dim V\) で表す。
    🔗
    🔗
    \(\mathrm{span}(\bm{v}_1,\dotsc,\bm{v}_m)\) の基底をもとめるためにアルゴリズム 4.3.3を使うことができる。
    🔗

    アルゴリズム 4.4.9. 基底の計算.

    問題
    • 入力:
      • \(\displaystyle \bm{v}_1,\dotsc,\bm{v}_m\in\mathbb{R}^n\)
        🔗
      • \(\bm{u}_1,\dotsc,\bm{u}_k\in\mathbb{R}^n\text{,}\) 線形独立
        🔗
      🔗
      🔗
    • 出力: \(1\le i_1\lt\dotsb\lt i_r\le m\) で \(\bm{u}_1,\dotsc,\bm{u}_k,\bm{v}_{i_1},\dotsc,\bm{v}_{i_r}\) が \(\mathrm{span}(\bm{u}_1,\dotsc,\bm{u}_k,\bm{v}_1,\dotsc,\bm{v}_m)\) の基底となるもの
      🔗
    は以下のアルゴリズムで解ける。
    🔗
    アルゴリズム 4.3.3を \(\bm{u}_1,\dotsc,\bm{u}_k,\bm{v}_1,\dotsc,\bm{v}_m\) に対して実行し、 \(\bm{u}'_1,\dotsc,\bm{u}'_k,\bm{v}'_1,\dotsc,\bm{v}'_m\) を得る。そして
    \begin{equation*} \left\{i\in\{1,\dotsc,m\}\mid \bm{v}'_i\ne\bm{0}\right\} \end{equation*}
    を出力する。
    🔗
    🔗

    証明.
    アルゴリズム 4.3.3より、
    \begin{equation*} \mathrm{span}(\bm{u}_1,\dotsc,\bm{u}_k,\bm{v}_1,\dotsc,\bm{v}_m)=\mathrm{span}(\bm{u}'_1,\dotsc,\bm{u}'_k,\bm{v}'_1,\dotsc,\bm{v}'_m) \end{equation*}
    である。零ベクトルを削除してもスパンは変化しないため、
    \begin{equation*} \mathrm{span}(\bm{u}_1,\dotsc,\bm{u}_k,\bm{v}_1,\dotsc,\bm{v}_m)=\mathrm{span}(\bm{u}'_1,\dotsc,\bm{u}'_k,\bm{v}'_{i_1},\dotsc,\bm{v}'_{i_r}) \end{equation*}
    である。
    🔗
    任意の \(j\in\{1,\dotsc,r\}\) について \(\bm{v}'_{i_j}\ne\bm{0}\) なので、\(\bm{v}_{i_j}\notin\mathrm{span}(\bm{u}_1,\dotsc,\bm{u}_k,\bm{v}_1,\dotsc,\bm{v}_{i_{j-1}})\) である。 よって、命題 4.2.7より、\(\{\bm{u}_1,\dotsc,\bm{u}_k,\bm{v}_{i_1},\dotsc,\bm{v}_{i_r}\}\) は線形独立である。
    🔗
    🔗

    練習問題 4.4.10. 基底の計算.

    以下の線形空間の基底を アルゴリズム 4.4.9 を用いて計算せよ。
    1. \begin{equation*} \mathrm{span}\left(\begin{bmatrix}1\\1\\0\\0\end{bmatrix},\begin{bmatrix}0\\1\\0\\1\end{bmatrix},\begin{bmatrix}1\\0\\0\\-1\end{bmatrix},\begin{bmatrix}1\\0\\0\\1\end{bmatrix}\right) \end{equation*}
      🔗
    2. 1と同じ線形空間。ただし基底に\(\begin{bmatrix}1\\0\\0\\0\end{bmatrix}\) を含めること。
      🔗
